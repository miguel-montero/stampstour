# Responsive Mobile Hero Images Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut mobile hero-image download weight 4-6x on the homepage and all 5 tour-type pages by adding mobile-sized WebP variants, without changing desktop visuals or any page's crop/framing.

**Architecture:** Generate one properly-encoded 780px-wide WebP per hero (except Maipo, already small — see Task 3), wrap each hero `<img>` in a `<picture>` with a `(max-width: 767px)` `<source>`, and extend `includes/head.php`'s existing `$lcp_preload_image` preload mechanism with two new optional variables so the browser's preload scanner also picks the correct variant per viewport.

**Tech Stack:** PHP (no framework), `cwebp`/`magick` (ImageMagick) for image generation, plain HTML `<picture>`/`srcset`.

## Global Constraints

- Mobile variants are generated at 780px width (headroom for ~2x DPR on a 390px viewport), `cwebp -q 80`, preserving each source's native aspect ratio. Exception: Maipo (Task 3).
- Do NOT reuse any existing `.webp` sibling file already on disk for Andes/Valpo/Cruise — verified this session to be badly encoded (larger than the current JPG in 2 of 3 cases). Every mobile variant in this plan must be freshly generated by the commands in Task 1.
- The `(max-width: 767px)` breakpoint is this codebase's established mobile breakpoint (already used throughout `css/style.css`/`includes/critical/*.css`) — use it verbatim, do not invent a different breakpoint.
- Every existing `width`/`height`/`alt`/`fetchpriority`/`class` attribute on each hero `<img>` must be preserved exactly as it is today — this plan only adds a `<picture>` wrapper and mobile `<source>`, it does not change any existing attribute value.
- `includes/head.php`'s new `$lcp_preload_image_mobile`/`$lcp_preload_image_width` variables must be optional — any page that doesn't set them (i.e., every page not touched by this plan) must render byte-for-byte the same preload `<link>` it renders today.
- **Line endings:** `discover-santiago-city-tour.php`, `maipo-valley-wine-tour-santiago.php`, `portillo-inca-lagoon-andes-mountains-vineyard.php`, `valparaiso-port-and-vina-del-mar-with-wine-tasting-in-casablanca.php`, and `cruise-transfer.php` use CRLF line endings; `index.php` and `includes/head.php` use LF. The code blocks in this plan are shown as plain LF text for readability — before editing any CRLF file, re-read its exact current lines with the Read tool and match against that, since an Edit tool `old_string` built purely from this plan's code blocks may not byte-match a CRLF file. Preserve each file's existing line-ending style; do not convert a CRLF file to LF (or vice versa) as a side effect of these edits.

### Task 2: Extend `includes/head.php`'s LCP preload mechanism

**Files:**
- Modify: `includes/head.php:13-17` (doc comment)
- Modify: `includes/head.php:113-115` (preload block)

**Interfaces:**
- Consumes: nothing from Task 1 (this task is independent PHP logic; can be tested with any two image paths).
- Produces: when a page sets `$lcp_preload_image_mobile` (string, root-relative path, no leading slash) AND `$lcp_preload_image_width` (int, actual pixel width of the `$lcp_preload_image` file) in addition to the existing `$lcp_preload_image`, `head.php` emits a responsive `<link rel="preload" as="image" imagesrcset="..." imagesizes="...">`. Pages that only set `$lcp_preload_image` (i.e., every page not touched by Tasks 3-5) get the exact same single-image preload `<link>` they get today. Tasks 3-5 set these three variables per page.

- [ ] **Step 1: Update the doc comment**

In `includes/head.php`, replace lines 13-17:

```php
 *   $lcp_preload_image (optional) - root-relative image path (no leading slash,
 *                        e.g. 'img/Tours/Maipo/big.jpg') for this page's LCP image.
 *                        When set and the file exists, it's preloaded with
 *                        fetchpriority="high" so it isn't starved by the deferred
 *                        stylesheet preloads above.
```

with:

```php
 *   $lcp_preload_image (optional) - root-relative image path (no leading slash,
 *                        e.g. 'img/Tours/Maipo/big.jpg') for this page's LCP image.
 *                        When set and the file exists, it's preloaded with
 *                        fetchpriority="high" so it isn't starved by the deferred
 *                        stylesheet preloads above.
 *   $lcp_preload_image_mobile (optional) - root-relative path to a mobile-sized
 *                        (780px wide) variant of $lcp_preload_image. When set
 *                        together with $lcp_preload_image_width and the file
 *                        exists, the preload becomes responsive via
 *                        imagesrcset/imagesizes: viewports <=767px preload this
 *                        file, wider viewports preload $lcp_preload_image.
 *   $lcp_preload_image_width (optional, required if $lcp_preload_image_mobile is
 *                        set) - actual pixel width (int) of $lcp_preload_image,
 *                        e.g. 1920. Must be accurate - it's the w-descriptor the
 *                        browser uses to pick between the two preload candidates.
```

- [ ] **Step 2: Update the preload block**

Replace `includes/head.php:113-115`:

```php
<?php if (!empty($lcp_preload_image) && is_file(__DIR__ . '/../' . $lcp_preload_image)): ?>
<link rel="preload" as="image" href="/<?= htmlspecialchars($lcp_preload_image, ENT_QUOTES, 'UTF-8') ?>" fetchpriority="high">
<?php endif; ?>
```

with:

```php
<?php if (!empty($lcp_preload_image) && is_file(__DIR__ . '/../' . $lcp_preload_image)): ?>
<?php if (!empty($lcp_preload_image_mobile) && !empty($lcp_preload_image_width) && is_file(__DIR__ . '/../' . $lcp_preload_image_mobile)): ?>
<link rel="preload" as="image" href="/<?= htmlspecialchars($lcp_preload_image, ENT_QUOTES, 'UTF-8') ?>" imagesrcset="/<?= htmlspecialchars($lcp_preload_image_mobile, ENT_QUOTES, 'UTF-8') ?> 780w, /<?= htmlspecialchars($lcp_preload_image, ENT_QUOTES, 'UTF-8') ?> <?= (int) $lcp_preload_image_width ?>w" imagesizes="(max-width: 767px) 780px, 100vw" fetchpriority="high">
<?php else: ?>
<link rel="preload" as="image" href="/<?= htmlspecialchars($lcp_preload_image, ENT_QUOTES, 'UTF-8') ?>" fetchpriority="high">
<?php endif; ?>
<?php endif; ?>
```
